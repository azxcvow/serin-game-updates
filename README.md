# Serin 게임 다운로드

[최신 버전 받기](https://github.com/azxcvow/serin-game-updates/releases/latest)

1. 최신 릴리스에서 **SerinLauncher-버전-Windows.zip**을 받으세요.
2. ZIP을 전부 풀고 **SerinLauncher.exe**를 실행하세요.
3. 이후부터 같은 실행기를 사용하면 새 게임 버전을 시작 전에 자동으로 받습니다.

기존 0.1.0 사용자는 이번에 한 번 실행기 ZIP으로 바꿔주세요. 업데이트 확인에 실패하면 설치된 정상 버전으로 시작합니다.

Windows 10/11 64비트 및 .NET Framework 4.8 환경용입니다. Godot, Blender, Codex, Python 설치는 필요 없습니다.

이 저장소는 게임 실행 파일과 서명된 업데이트 배포용입니다. 엔진과 포함 라이브러리의 라이선스는 게임 폴더의 `licenses`에 있습니다.
